## 🧠 Core Learning Philosophy

For every topic, the learning progression will be:

`CONCEPT` → `TINY EXAMPLE` → `CLOSE THE EXAMPLE` → `WRITE FROM MEMORY` → `RUN` → `DEBUG` → `DSA APPLICATION` → `INTERVIEW QUESTION`

The overarching problem-solving flow this curriculum trains:
`PROBLEM` → `UNDERSTAND LOGIC` → `CHOOSE DATA STRUCTURE` → `KNOW REQUIRED JAVA TOOL/API` → `WRITE CODE` → `TEST` → `DEBUG` → `OPTIMIZE`

* **Goal**: Focus on coding capabilities. Learn just enough syntax → code immediately → use it in DSA → build fluency. 

---

## ⚠️ Important Rules & Expectations

- 🚫 **No Hand-Holding**: Regular **Blank Editor Challenges** where only the problem description is provided. You must write the implementation completely from memory.
- 🎯 **80/20 Rule**: Focus on the 20% of Java APIs that solve 80% of DSA implementation problems. No exhaustive memorization of unused methods.
- 🧠 **Code Conversion Training**: Direct focus on translating `ALGORITHM THOUGHT` → `PSEUDOCODE` → `JAVA SYNTAX`.
- 🔍 **Debugging Training**: Identify bugs, predict behavior, explain why it fails, and fix the code.
- 💡 **Pattern Recognition**: Learn mapping rules (e.g., "Need sorted keys" → `TreeMap`, "Need LIFO" → `ArrayDeque`).
- ⚡ **Complexity Analysis**: Time and space complexity evaluated practically based on the internal workings of Java data structures.

## 📚 Syllabus

<div align="center">

| Phase | Topics Covered | Key Outcomes |
| :--- | :--- | :--- |
| **1. Language Foundation** | Primitives vs References, Casting, Math, Wrapper Classes | Write structurally sound Java without basic syntax errors. |
| **2. Stdlib API Toolkit** | The 20% of String, Arrays, Math, and Collections APIs that matter | Rapidly translate algorithms into Java code using standard tools. |
| **3. Collections Framework** | ArrayList vs LinkedList, Hash vs Tree (Map/Set), Queues vs Deques | Choose the correct Java Collection based on time-complexity needs. |
| **4. DSA Implementation Patterns** | Frequency Maps, Visited Sets, Two Pointers, Monotonic Stacks | Master the boilerplate Java setups for FAANG patterns. |
| **5. Strings & Char Handling** | StringBuilder, indexOf, split, Character.isLetterOrDigit | Confidently implement Palindromes, Anagrams, String Compression. |
| **6. Arrays** | Arrays.sort, Arrays.fill, 2D/Jagged Arrays | Complete mastery over array manipulation and memory references. |
| **7. Methods & Recursion** | Call stack, base cases, reference passing | Recursion tree visualization and backtracking foundations. |
| **8. DSA OOP & Comparators** | Comparable vs Comparator, Encapsulation | Sort custom objects and structure graph/tree Nodes. |
| **9. Custom Data Structures** | Implementing Linked Lists, Trees, Graphs, Tries from scratch | Never panic when an interview asks you to build a custom class. |
| **10. Trees & Graphs** | BFS/DFS, Adjacency Lists, Visited Arrays | Standardize your Java boilerplate for graph and tree traversals. |
| **11. Heaps & Priority Queues** | Min/Max Heaps, Custom Comparators | Ace Top-K, scheduling, and Kth-largest problems. |
| **12. Sorting & Searching** | Arrays.sort vs Collections.sort, Binary Search APIs | Advanced sorting of custom multi-variable objects. |
| **13. I/O for Coding Rounds** | Scanner vs BufferedReader, StringTokenizer, StringBuilder output | Handle large IO without Time Limit Exceeded (TLE) errors. |
| **14. Exceptions & Debugging** | NPE, IndexOutOfBounds, ClassCastException | Instantly identify and fix broken Java code. |
| **15. Memory & Behavior** | Stack vs Heap, Pass-by-value, Immutability, `==` vs `.equals()` | Stop making confusing object-reference mistakes. |
| **16. Generics & Lambdas** | `<T>`, Wildcards, Lambda Comparators | Read and write modern, clean generic Java code. |
| **17. Implementation Bootcamp** | 15+ Core FAANG problems trained in a blank editor | Total synthesis of Java syntax + DSA logic. |
| **18. Final Mastery Test** | API Recall, Debugging, Tool Selection, Conversion, Blank Editor | Prove you are ready for a real-world coding round. |
