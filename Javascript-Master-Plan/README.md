## 🧠 Core Learning Philosophy

For every topic, the learning progression will be:

`WHY` → `WHAT` → `MENTAL MODEL` → `SYNTAX` → `SMALLEST POSSIBLE EXAMPLE` → `MANUAL IMPLEMENTATION` → `PRACTICAL USE` → `EDGE CASES` → `COMMON MISTAKES` → `DEBUGGING` → `REAL-WORLD ENGINEERING CONNECTION` → `INTERVIEW QUESTION` → `HAND-CODING EXERCISE`

* **Goal**: Understand the smallest building blocks first. Do NOT jump directly to large projects.

---

## ⚠️ Important Rules & Expectations

- 🚫 **No AI Dependency**: No immediate full solutions for exercises. 
- 🔄 **Flow**: `UNDERSTAND` → `CLOSE AI` → `WRITE CODE` → `TEST` → `DEBUG` → `REVIEW`. (Solutions will be hidden under a "REFERENCE SOLUTION" section).
- 🗣️ **Explanation Style**: Simple technical language (as if explaining to an interviewer). Small examples. No unnecessary academic jargon.
- 💻 **Code Style**: Plain JavaScript only. No React/Node/TypeScript until the concept naturally requires it. Future applications will be marked as `"WHERE YOU WILL SEE THIS LATER"`.
- 🏭 **Industrial Connection**: Explain where and why concepts appear in real-world software.
- ⚖️ **Implementation Distinction**: Clear separation between `### LEARNING IMPLEMENTATION` and `### REAL-WORLD CONSIDERATION`.
- 🐛 **Debugging Training**: Debugging exercises (syntax, logic, runtime errors) in every major phase.
- ⌨️ **Hand-Coding Training**: Every phase ends with `### WRITE WITHOUT AI` containing 3–5 gradual coding tasks.
- 🏗️ **Phase Projects**: One small summary project per phase. Code will not be fully provided.

## 📚 Syllabus

<div align="center">

| Phase | Topics Covered | Capstone Project |
| :--- | :--- | :--- |
| **1. Fundamentals** | Variables, Functions, Scope, Conditionals, Loops, Template literals | Calculator / CLI mini program |
| **2. Data Structures** | Arrays, Objects, Nested data, Local storage, Array destructuring | Student data manager |
| **3. Algorithms** | Bubble, Selection, Insertion Sort, Recursion, Palindrome | Algorithm playground |
| **4. DOM Manipulation** | querySelector, innerHTML, textContent, Dynamic creation | Dynamic Todo UI |
| **5. Event Handling** | Click listeners, Keyboard events, Form submissions, Change | Interactive form |
| **6. OOP + ES6+** | Classes, Instances, Destructuring, Default params, Object.freeze() | Small OOP application |
| **7. Regular Expressions** | Pattern matching, Capture groups, Flags, test(), replace(), match() | Form validation engine |
| **8. Async JavaScript** | fetch(), Promises, async/await, Error handling, API integration | API-based dashboard |
| **9. Array Methods** | map(), filter(), reduce(), sort(), forEach(), some(), slice(), join() | Data transformation dashboard |
| **10. String Manipulation** | split(), replace(), toLowerCase(), reverse(), Template literals | Text processing utility |
| **11. Form Handling** | Input validation, Form submission, preventDefault() | Validated registration form |
| **12. Game Development** | Canvas API, Game loops (requestAnimationFrame), Physics, Collision | Small Canvas game |
