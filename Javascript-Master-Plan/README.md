# JAVASCRIPT — INDUSTRIAL DEVELOPMENT + INTERVIEW + HAND-CODING MASTER PLAN

## CORE LEARNING PHILOSOPHY
For every topic, the learning progression will be:

`WHY` → `WHAT` → `MENTAL MODEL` → `SYNTAX` → `SMALLEST POSSIBLE EXAMPLE` → `MANUAL IMPLEMENTATION` → `PRACTICAL USE` → `EDGE CASES` → `COMMON MISTAKES` → `DEBUGGING` → `REAL-WORLD ENGINEERING CONNECTION` → `INTERVIEW QUESTION` → `HAND-CODING EXERCISE`

* **Goal**: Understand the smallest building blocks first. Do NOT jump directly to large projects.

## IMPORTANT RULES & EXPECTATIONS

1. **Write Code Yourself**: 
   - No immediate full solutions for exercises. 
   - Flow: `UNDERSTAND` → `CLOSE AI` → `WRITE CODE` → `TEST` → `DEBUG` → `REVIEW`.
   - Solutions will be hidden under a "REFERENCE SOLUTION" section.
2. **Explanation Style**: 
   - Simple technical language (as if explaining to an interviewer).
   - Small examples. No unnecessary academic jargon.
3. **Code Style**: 
   - Plain JavaScript only. No React/Node/TypeScript until the concept naturally requires it.
   - Future applications will be marked as `"WHERE YOU WILL SEE THIS LATER"`.
4. **Industrial Connection**: 
   - Explain where and why concepts appear in real-world software.
5. **Implementation Distinction**: 
   - Clear separation between `### LEARNING IMPLEMENTATION` and `### REAL-WORLD CONSIDERATION`.
6. **Debugging Training**: 
   - Debugging exercises (syntax, logic, runtime errors) in every major phase.
7. **Hand-Coding Training**: 
   - Every phase ends with `### WRITE WITHOUT AI` containing 3–5 gradual coding tasks.
8. **Phase Projects**: 
   - One small summary project per phase. Code will not be fully provided.
